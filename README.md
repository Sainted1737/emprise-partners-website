# Emprise Partners website

Source for [emprise-partners.com](https://emprise-partners.com). A static site: plain HTML, CSS and JavaScript, with no build step. Hosted on Netlify, which publishes the `main` branch automatically.

## Pages

- `index.html` — Home
- `about.html` — About
- `services.html` — Services
- `past-performance.html` — Past performance
- `partners.html` — Trade partners
- `contact.html` — Contact and FAQ
- `privacy.html` — Privacy Policy
- `terms.html` — Terms of Use

## Other files

- `site.css` — styles
- `site.js` — mobile menu, day/night hero photo, and form handling
- `photo-*.jpg` — photography (Unsplash license)
- `Emprise_Partners_Capability_Statement.pdf` — capability statement
- `build.py` — regenerates the HTML pages from shared content; run `python3 build.py` after editing it
