Add it to Outlook

Outlook on Mac
  1. Click Copy signature above.
  2. In Outlook, go to Outlook → Settings → Signatures (in the newer Outlook: Settings → Accounts → Signatures).
  3. Click + to add a new one, name it "Emprise Partners", and delete any text in the box.
  4. Click in the box and press Cmd+V to paste.
  5. Set it as the default for New messages and Replies/forwards, then save.
Outlook on Windows PC (HP, Dell, etc.)
  1. Open this page in Chrome or Edge and click Copy signature.
  2. New Outlook: Settings (gear) → Accounts → Signatures. Classic Outlook: File → Options → Mail → Signatures.
  3. Click New signature, name it "Emprise Partners", click in the box and press Ctrl+V.
  4. Choose it as the default for new messages and replies/forwards, then Save.
Outlook on iPhone
  1. Click Copy phone version above (or open this page on your phone and tap it).
  2. In the Outlook app, tap your profile picture → Settings (gear) → Signature.
  3. Delete "Get Outlook for iOS", paste, and tap back to save.

The iPhone app only shows plain text signatures, so the phone version has no logo. That's normal.

If the paste doesn't work

Click inside the preview box, press Cmd+A (Mac) or Ctrl+A (PC) to select it, copy, and paste into Outlook.
